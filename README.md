# 🚀 HackJudge AI

**HackJudge AI** is an intelligent, streamlined platform designed to revolutionize the hackathon experience. It bridges the gap between students, judges, and organizers by automating and simplifying project evaluation, category discovery, and global hackathon tracking.

🔗 **Live Demo:** [hack-judge-ai.vercel.app](https://hack-judge-ai.vercel.app)

---

## 📌 Features

### ⚖️ For Judges
* **Effortless Evaluation:** Score projects seamlessly through an intuitive interface.
* **Fair Assessment:** Standardized metrics to ensure objective grading.

### 🎓 For Students
* **Project Discovery:** Browse through past hackathon project descriptions and ideas categorized by domains (e.g., **Health**, **Education**, **Fintech**, etc.).
* **Instant Feedback:** Gain insights into how projects are scored to improve future submissions.

### 🌐 Global Hackathon Tracker
* **Live & Upcoming Events:** Stay ahead of the curve with a curated, real-time list of hackathons happening all around the world.

---

## 🛠️ Tech Stack

This project is built using a modern, scalable web development stack:

* **Frontend Framework:** React with TypeScript (`.tsx`)
* **Build Tool:** Vite (for ultra-fast development and bundling)
* **Language:** TypeScript (ensuring type safety and robust code)
* **Deployment:** Vercel
