# 🚀 HackJudge AI

**HackJudge AI** is an intelligent, streamlined platform designed to revolutionize the hackathon experience. It bridges the gap between students, judges, and organizers by automating and simplifying project evaluation, category discovery, and global hackathon tracking.

🔗 **Live Demo:** https://hack-judge-ai.vercel.app

---

## 📌 Features

### ⚖️ For Judges

* **Effortless Evaluation:** Score projects seamlessly through an intuitive interface.
* **Fair Assessment:** Standardized metrics to ensure objective grading.
* **Structured Reviews:** Evaluate submissions consistently across categories.

### 🎓 For Students

* **Project Discovery:** Browse hackathon project descriptions and ideas categorized by domains such as Health, Education, Fintech, AI, Sustainability, and more.
* **Learning Resource:** Explore past project concepts for inspiration.
* **Instant Insights:** Understand evaluation criteria and scoring approaches.

### 🌐 Global Hackathon Tracker

* **Live & Upcoming Events:** Discover hackathons from around the world.
* **Centralized Information:** Access event details from a single platform.
* **Stay Updated:** Never miss new opportunities to participate and learn.

## 🚀 Getting Started

### Prerequisites

* Node.js (v18 or higher recommended)
* npm or yarn

### Installation

```bash
# Clone the repository
git clone <repository-url>

# Navigate into the project
cd hackjudge-ai

# Install dependencies
npm install
```

### Run Locally

```bash
npm run dev
```

The application will be available at:

```bash
http://localhost:5173
```

### Build for Production

```bash
npm run build
```
